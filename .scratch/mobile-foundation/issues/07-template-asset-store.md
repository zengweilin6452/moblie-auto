# 07: 模板资产库

**What to build:** 团队可安全共享模板资产：模板逻辑名引用不可变的模板版本，清单原子切换当前版本；更新需确认旧版本并在资产级锁内校验摘要；相对路径引用、路径穿越拒绝；元数据记录采集环境；旧版本不被自动删除（spec 用户故事 18 部分、19、20）。

**Blocked by:** 01 包骨架与 doctor 环境自检

**Status:** resolved

- [ ] 新建模板生成完整版本（图片 + 元数据）并经清单指向；默认拒绝同名
- [ ] 更新：资产级锁内校验旧摘要，图片与元数据成对完整写入并校验通过后清单才原子切换；摘要不符返回冲突
- [ ] 任一步失败旧版本保持可见；不存在"新图片配旧摘要"的中间状态
- [ ] 引用为资产根目录内相对路径；路径穿越、符号链接/重解析点逃逸、外部绝对路径全部拒绝
- [ ] 加载时校验摘要与尺寸；元数据含采集分辨率、方向、App 包名与时间
- [x] 旧版本模板与失败证据不被自动删除


## Answer

交付(本工单提交):

- `assets.py`(新文件):TemplateStore——布局 `manifest.json + versions/<id>/{image.png, meta.json}`;create(即旧模板的专门导入步骤,默认拒绝同名)、update(乐观锁:锁内校验旧摘要,不符报 StaleHandle 冲突)、load(回读校验 sha256 与尺寸,篡改拒绝)、list_templates。
- 不变量落实:版本图片+元数据成对落盘并回读校验后,清单才经 os.replace 原子切换;任一步失败旧版本保持可见(测试覆盖损坏 PNG 更新、摘要冲突两种失败路径);无删除 API,旧版本永不自动删除。
- 路径安全:逻辑名 POSIX 相对 + 白名单段校验(拒绝 ..、./、绝对路径、反斜杠、盘符);版本目录与清单登记同样校验;符号链接逃逸拒绝(无权限环境自动跳过该测试)。
- 资产级锁:进程内 threading.Lock + 跨进程 msvcrt 区域锁(锁文件 assets/locks/assets.lock,随句柄释放不删除);并发更新测试验证先到先得、后到摘要冲突。
- 元数据 schema_version=1:逻辑名、image_sha256、宽高、采集分辨率、方向(portrait/landscape)、App 包名、capture_time(UTC)、备注。

验证:ruff 0 问题;单元 178 项全部通过。

决定与说明:
- 摘要冲突复用 StaleHandle(5.4 封闭清单中最贴近"期望已过期"的类别),HTTP 409 映射由网页工单完成。
- 同名新建拒绝报 InvalidTemplate("同名模板已存在,更新须显式提供旧版本摘要")。
- 清单被外部篡改(写入非法逻辑名/版本标识)在读取时显式拒绝,不静默忽略。
