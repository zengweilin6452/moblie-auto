# 04: 跨进程设备租约与取消语义

**What to build:** 测试与调试不再争用设备、用例超时不再引发重复业务操作：跨进程文件租约按设备序列号加锁；每个操作带发送阶段取消检查点；会话故障进入 FAULTED 后拒绝后续设备操作且取证降级（spec 用户故事 24、25、26）。

**Blocked by:** 02 设备会话与第一条真机用例

**Status:** open

- [ ] 第二进程请求忙设备立即得到 busy，不排队抢占；锁文件统一目录、按设备序列号摘要命名
- [ ] 模拟设备下"匹配完成后、点击发送前取消"不发出点击（确定性测试）
- [ ] 已进入发送阶段的操作被取消：结果记为 unknown，不自动重放相同动作
- [ ] 排队未开始的任务可取消；运行中的在途调用结束前不释放租约
- [ ] FAULTED 会话拒绝新设备操作；失败取证不再调用挂起的设备线程
- [ ] close 排空有界，超时报会话故障；重复关闭安全；锁随进程退出释放，不靠删文件或过期时间偷锁
- [ ] 会话状态机转换有测试覆盖；session 级 fixture 与 function 级事件循环组合验证通过
