# 08: IMAGE 驱动操作

**What to build:** UI 树覆盖不了的视觉目标也能自动化：IMAGE 定位描述驱动 click、is_visible、wait_for、find_elements——每次新采集截图匹配、点击为完整设备事务；图像查询句柄带身份校验，页面重排后报句柄过期而非点错目标；不支持的操作组合明确报错（spec 用户故事 13、16、17）。

**Blocked by:** 02 设备会话与第一条真机用例；06 图像匹配引擎；07 模板资产库

**Status:** open

- [ ] 真机用例：用模板点击演示 App 的视觉目标，后置业务断言通过
- [ ] click 单目标要求唯一匹配或显式序号；多目标无序号报歧义，不自动取最高分
- [ ] 采集完成到点击超时则重新采集一次，再超时失败，不无限重试；事务内无其他设备请求插队
- [ ] 图像句柄重用校验模板摘要、会话、尺寸方向与位置一致性；身份不明报句柄过期（含列表插入/删除重排场景）
- [ ] input_text、get_text、get_attribute、extract_list 对 IMAGE 明确报不支持（各有测试）
- [ ] 匹配无结果是明确的查询结果（空列表/False），非法模板与设备错误分开报告
- [ ] 模拟设备验证取消窗口贯通：发送阶段检查点在 IMAGE 路径同样生效
