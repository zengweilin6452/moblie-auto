# 03: 原生定位与操作补全

**What to build:** 原生能力全量可用：XPath、可访问性描述、u2 选择器（JSON 白名单字段）三种定位描述补全，index 与歧义规则；输入为清空替换且拒绝不可编辑目标；属性读取区分未知与缺失；返回/按键/滚动有确定语义；goto 受 Deep Link 白名单约束；wait_for_load 仅等待启动就绪目标；is_visible/find_elements/close/错误分类齐全；原生查询句柄重用校验；UI 树获取与归一化（spec 用户故事 4–12）。

**Blocked by:** 02 设备会话与第一条真机用例

**Status:** open

- [ ] 五种原生定位描述全部可用；u2 选择器拒绝未知字段、代码与正则；index 拒绝 bool、负数与字符串数字
- [ ] find_elements 无序号返回全部可见匹配、有序号返回至多一个，顺序为树遍历序
- [ ] input_text 清空并替换；不可编辑目标明确失败，不以全局输入冒充
- [ ] get_attribute：布尔以 true/false 字符串返回、bounds 为固定四整数、未知属性报错、已知缺失返回空串
- [ ] scroll 方向语义（down = 内容上移）、amount 夹限到安全区域；press_key 有限键表、未知键报错
- [ ] goto：空串启动配置 App；非空仅接受白名单 scheme，未配置或非法报配置错误，不执行任意 shell
- [ ] wait_for_load 仅等待启动就绪目标，缺配置报错，不以固定 sleep 替代
- [ ] close 幂等；异常分类可区分非法定位描述、定位超时、匹配歧义、设备不可用、不支持、取消
- [ ] 原生句柄重用：关键属性不一致或会话变化报句柄过期，不指向新节点
- [ ] UI 树归一化（节点、父子关系、bounds、属性）产出可供失败证据与网页复用
- [ ] 真机操作矩阵（正常/失败/边界）在演示 App 上通过；CSS 定位描述明确报不支持
