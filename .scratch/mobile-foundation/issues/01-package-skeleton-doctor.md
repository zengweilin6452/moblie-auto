# 01: 包骨架与 doctor 环境自检

**What to build:** 测试工具开发者可以安装本包并用一条命令确认环境可用：包可编辑安装，CLI 提供 doctor 子命令，报告依赖版本、ADB 可见性与已授权设备在线状态；缺依赖时非零退出且不修改设备。doctor 仅执行无副作用检查，设备端组件初始化是独立显式步骤（spec 用户故事 1、2 的环境部分）。

**Blocked by:** None (can start immediately)

**Status:** in-progress

- [ ] 可编辑安装成功；公开导出可导入且导入无设备副作用
- [ ] doctor 报告依赖版本与 ADB 可见性；缺依赖非零退出并列出缺失项
- [ ] doctor 区分已授权在线设备 / 未授权 / 无设备，不自动选择设备
- [ ] doctor 不触发设备端组件初始化、不安装、不写入设备
- [ ] 配置合并生效：显式参数 > 环境变量 > TOML > 默认值；非法值报配置错误
- [ ] lint 与单元测试在干净检出上可运行
