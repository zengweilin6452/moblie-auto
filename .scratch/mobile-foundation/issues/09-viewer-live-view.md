# 09: 网页服务骨架与实时查看

**What to build:** 不安装桌面工具即可查看设备：本机网页显示实时预览帧与 UI 树（各自标注采集时间）、设备忙/离线状态；快照冻结与编辑期固定引用；仅监听回环并校验请求来源；资源上限全部生效；无设备时服务仍可启动并如实报告（spec 用户故事 27、30 部分、31）。

**Blocked by:** 03 原生定位与操作补全；04 跨进程设备租约与取消语义

**Status:** open

- [ ] serve 启动后浏览器可见实时预览帧（默认 1fps）与可刷新 UI 树，分别标注采集时间
- [ ] 快照接口返回截图与树绑定同一快照标识；采集间隔超限提示不一致并禁用原生拾取
- [ ] 编辑期间冻结快照固定引用，不受实时快照份数上限驱逐；退出编辑或超时后释放
- [ ] pytest 持有租约时网页显示占用状态且不主动采集；设备忙/离线/未连接状态明确区分
- [ ] 仅监听回环地址；来源校验拒绝跨源请求；WS 最多 2 客户端、慢客户端丢帧不堆积
- [ ] 像素、文件大小、快照份数与总量、匹配作业并发上限生效，超限明确提示不积压
- [ ] 错误码映射（422/404/409/400/503/504）含 code、用户可读信息与 request_id
