# 05: 失败证据与运行清单

**What to build:** 用例失败后现场可复盘：自动保存新截图、UI 树、异常与各自采集时间，区分操作时画面与事后取证画面；证据写入产物目录并登记运行清单（后续网页读取的唯一入口）；设备会话故障挂起时降级留证（spec 用户故事 21、22 部分、23）。

**Blocked by:** 03 原生定位与操作补全

**Status:** open

- [ ] 真机失败用例产出证据：截图、UI 树、异常类型、时间、设备与 App 基线，各自带采集时间与失败原因
- [ ] 操作时使用的画面与失败后新采集的画面分开保存并标注，不互相冒充
- [ ] 证据写入配置的产物目录并登记运行清单；清单是唯一读取入口
- [ ] 初始化失败与清理失败保留原始测试错误，不被取证错误覆盖
- [ ] 会话故障时只保存已有材料并记录"无法采集"原因
- [ ] 取证有超时，失败用例不因取证挂起；日志与证据不含输入文本与凭据
