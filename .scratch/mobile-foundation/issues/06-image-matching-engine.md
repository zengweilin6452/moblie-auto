## Answer

交付(本工单提交):

- `image.py`(新文件,plan §10 的 image 职责):`match_template` 纯函数——截图与模板解码为一致 8-bit RGB(`decode_rgb` 拒绝透明蒙版与损坏 PNG);ROI 四整数完全落界校验不静默裁切;灰度 TM_CCOEFF_NORMED 候选定位,8 邻域局部峰值、同分 (y,x) 稳定;NMS IoU>0.30 抑制;结果还原全截图坐标按 (y,x) 排序,center 为边界中心;每个候选经颜色验证(RGB 均值绝对差 ≤ COLOR_DIFF_MAX),状态色不同拒绝、同色渲染差异(JPEG-85 重编码真实样本)接受;低纹理(灰度标准差<2)、非有限分数、峰值>2000、结果>100 均显式拒绝。
- 校准初值集中在模块:GRAY_STDDEV_MIN=2、DEFAULT_CONFIDENCE=0.90、NMS_IOU=0.30、MAX_PEAKS=2000、MAX_MATCHES=100、COLOR_DIFF_MAX=16、坐标容差 2px;README(测试样本目录)登记调整记录要求。
- 样本集:`tests/fixtures/images/` 12 组真实正负样本(设置主页/WLAN 子页/滚动页截图 + 元素级裁剪模板 + JPEG-85 渲染差异正样本 2 组 + 负样本 5 组,含彩色图标通道对调的状态色负样本)+ samples.json 清单 + README 登记来源与校准依据。
- 测试:合成样本 17 项(坐标精确、排序、区域偏移、渲染差异、状态色、各拒绝路径、溢出)+ 真实样本 13 项(≥10 组要求)。

验证:ruff 0 问题;单元 163 项全部通过。

决定与说明:
- OpenCV 5.0.0 / NumPy 2.5.4(image extra 安装验证);cv2 通道序在 decode_rgb 统一转 RGB,调用方只接触 RGB。
- 真实样本的"状态色不同"负样本须取自有色元素(彩色图标):灰阶文本裁剪通道对调后像素不变,不能充当颜色负样本(踩坑已记录)。
- 引擎不依赖驱动、网页或 numpy 之外的运行时状态;供内网 ImageMatcher 以同一样本集对照(样例即 tests/fixtures/images)。
