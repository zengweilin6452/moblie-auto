# 02: 设备会话与第一条真机用例

**What to build:** 移动测试工程师可以在配置的演示 App 上运行第一条真机用例：建立设备会话，按资源 ID 或文本定位原生控件，等待可见后点击，读取文本断言，采集 PNG 截图。本票同时固定演示 App 的来源、版本与摘要并登记场景清单（spec 用户故事 2、4、5、7 的首个切片）。

**Blocked by:** 01 包骨架与 doctor 环境自检

**Status:** in-progress

- [ ] 设备会话建立与关闭；无设备、多设备未选、序列号错误、未授权均为明确错误，不误选设备
- [ ] resource_id 与 text 精确匹配定位；唯一匹配可点击，多匹配无序号报歧义
- [ ] wait_for 返回 bool 且可取消；"未找到"与"设备错误"区分报告
- [ ] screenshot 返回新采集的 PNG bytes，不返回缓存帧
- [ ] 演示 App 的来源、版本、摘要与场景清单已登记入文档
- [ ] 真机用例（启动 → 定位 → 点击 → 断言 → 截图）在演示 App 上通过；无设备时用例显示未执行、不计为通过
